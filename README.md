# Nuna — публичные дистрибутивы

В этом репозитории публикуются только готовые Android-пакеты и метаданные обновлений. Исходный код Nuna находится в отдельном приватном репозитории и сюда не копируется.

- [Последний стабильный релиз](https://github.com/rds13-gh/nuna-releases/releases/latest)
- [Манифест последнего обновления](https://github.com/rds13-gh/nuna-releases/releases/latest/download/latest.json)

Каждый релиз содержит подписанные APK и AAB, `SHA256SUMS` и `latest.json`. Приложение с ручной установкой использует манифест для проверки новой версии; перед установкой Android дополнительно проверяет хэш, имя пакета, номер версии и сертификат подписи.

До первого опубликованного релиза ссылки на файлы могут возвращать 404.
